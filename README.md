# Mobile App – Dashboard & Program Details Screens

This repo contains wireframes and descriptions for the Dashboard and Program Details screens of the mobile app.

## Screens
- **Dashboard:** Displays announcements and upcoming events
- **Program Details:** Shows program info and registration options

## Navigation Flow
Home → Browse Programs → Program Listing → Program Details → Feedback Form
